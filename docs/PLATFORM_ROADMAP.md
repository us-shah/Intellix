# Intellix Unified Platform

## Included in this upgrade
- Shared login and role-aware redirect
- Student self-registration
- Client self-registration and company profile
- Super Admin/Admin permission APIs
- LMS courses, lessons, enrollment, assignments, submissions and grading APIs
- Student dashboard starter
- Client dashboard starter
- SQL Server V2 upgrade script

## Roles
SUPER_ADMIN, ADMIN, MANAGER, SALES, INSTRUCTOR, STUDENT, CLIENT, HR, FINANCE, SUPPORT.

## Still required for a truly complete production platform
1. Refresh/logout token revocation and password recovery email.
2. Full admin UI for permissions, courses, lessons, enrollments and grading.
3. Client projects, invoices, payments, documents, meetings and support tickets linked by ClientProfileID.
4. Quizzes, attendance, certificates, live classes and course completion rules.
5. File upload/storage, email, notifications and audit automation.
6. Database migrations, automated tests, Docker, CI/CD and deployment.

This upgrade is a strong functional foundation, not a claim that every enterprise module is finished.
